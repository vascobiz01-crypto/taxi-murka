# TAXI МУРКА — Android-проект

Это исходный проект настоящего Android-приложения (оболочка WebView с локальной HTML-панелью).

## Что уже включено
- Название приложения: TAXI МУРКА
- Открытие панели офлайн, без браузера
- Локальное хранение записей через WebView DOM Storage / localStorage
- Доход безналом, расходы (бензин, мойка, ТО и прочее)
- Часы за рулём, километраж, средний заработок в час
- Цель 15 000 ₽, сводка за день / неделю / месяц
- История смен

## Как собрать APK
Нужна среда Android Studio или AndroidIDE с Android SDK (API 35) и JDK 17.

1. Распакуйте архив.
2. Откройте папку `TaxiMurka` как Gradle-проект.
3. Дождитесь синхронизации Gradle.
4. Выберите Build > Build APK(s).
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Для Android Studio: используйте Gradle 8.9 и Android Gradle Plugin 8.7.3.

## Важно
В этой среде Android SDK и Gradle не установлены, поэтому готовый APK здесь не собран. Архив содержит исходный Android-проект, который можно собрать в Android Studio / AndroidIDE.
Данные пока хранятся локально на телефоне внутри приложения. Удаление приложения или очистка его данных может удалить записи. Рекомендуется регулярно экспортировать резервную копию после добавления поддержки экспорта в Android-версии.
